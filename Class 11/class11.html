We can now use the identified core atom positions as a basis for a more suitable superposition and write out the fitted structures to a directory called corefit_structures:

core.inds <- print(core, vol=0.5)

xyz <- pdbfit(pdbs2, core.inds, outpath="corefit_structures")

The resulting superposed coordinates are written to a new director called corefit_structures/. We can now open these in Mol* and color by the Atom Property of Uncertainty/Disorder (i.e. the B-factor column that contains the pLDDT scores).

Note that models 3, 4, and 5 are quite dissimilar and of questionable quaility as we will see with thir PAE scored below.

Now we can examine the RMSF between positions of the structure. RMSF is an often used measure of conformational variance along the structure:

Determining RMSF:

rf <- rmsf(xyz)

plotb3(rf, sse=pdb)
abline(v=100, col="gray", ylab="RMSF")

This shows that the first chain is largely very similar across the different models. However, the second chain is much more variable.

Predicted Alignment Error for domains (HIV-Pr Dimer)

Independent of the 3D structure, AlphaFold produces an output called Predicted Aligned Error (PAE), detailed in the JSON format result files, one for each model structure.

Below we read these files and see that AlphaFold produces a useful inter-domain prediction for model 1 (and 2) but not for model 5 (or indeed models 3, 4, and 5):
